# 网速测试 · Speed Test

> 在浏览器里直接测延迟、下行与上行速度。不装 App、不注册、不经任何第三方测速页面。

[English](README.md) | **简体中文**

<a href="https://bushimashen.github.io/speed-test/"><b>▶ 在线试用</b></a>

## 能测什么

- **延迟** —— 打 6 次往返取中位数，单次抖动不会污染结果
- **下行** —— 4 线程并发拉流、跑满 9 秒；一条请求 100ms 内下完就自动把块大小翻倍
- **上行** —— 2 线程并发 POST **密码学随机**数据、跑满 8 秒
  （必须用随机数据：全零缓冲会被传输层压缩，测出来的上行会虚高）
- **实时表盘** —— 1~1000 Mbps 对数映射，5 Mbps 的小水管也能看到指针真的在动
- **评级** —— 按下行速度给一句人话结论

## 为什么用公共测速节点

测速总得有个对端。这个工具**故意没有后端**，直连 Cloudflare 的公开测速端点
（`speed.cloudflare.com/__down` 与 `/__up`），它会返回随机字节并带 `Access-Control-Allow-Origin: *`，不需要密钥。

好处是整个工具就是一个 HTML 文件；代价是**测的是你到最近 Cloudflare 节点的链路**，
而不是到某个指定服务器。想知道「我这网多快」，这是对的口径；想给某一台机器做基准，那就不合适了。

**换成自己的服务器** —— 改脚本顶部三个常量：

```js
const NODE     = 'https://speed.cloudflare.com'
const DOWN_URL = (bytes) => `${NODE}/__down?bytes=${bytes}`   // GET  -> 返回 N 个随机字节
const UP_URL   = `${NODE}/__up`                               // POST -> 返回 2xx 即可
```

自建端点**必须**返回 `Access-Control-Allow-Origin`，否则浏览器读不到响应，测速会静默变成 0。

## 怎么用

下载 `index.html` 双击打开，或用本地服务：

```bash
python -m http.server 8000
```

> `file://` 下部分浏览器会拒绝跨域 `fetch`。如果一点开就报错，用上面的本地服务方式。

## 结果怎么算

```
延迟   = median(rtt[0..5])
下行   = 总字节 × 8 / 1e6 / 9      (Mbps)
上行   = 总字节 × 8 / 1e6 / 8      (Mbps)
```

两个吞吐阶段都是**固定时长**而不是固定字节数：慢链路上不会因为块拉不完而算错，快链路上也不会灌爆流量。

## 注意

- 测上行**真的会消耗流量**，量级约等于「结果 × 8 秒」。
- 结果受 WiFi、时段、运营商互联质量影响，单次结果只是快照。
- 没有任何统计上报，除了测速请求本身，页面不往外发东西。
